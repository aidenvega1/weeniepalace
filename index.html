Research Project

Identifying previously uncataloged variable astronomical objects using machine learning on NASA NEOWISE infrared time-series data.

Project Overview

This research project re-analyzes archival data from NASA's NEOWISE infrared space telescope to identify variable objects that were not previously flagged by traditional survey pipelines.

Instead of searching for known object classes, the project uses anomaly detection on infrared light curves to discover unusual variability patterns—similar in methodology to recent large-scale discoveries made using AI-driven approaches.

Scientific Motivation

  • Infrared variability is underexplored compared to optical data
  • Many objects remain unclassified in existing catalogs
  • Machine learning enables discovery at massive data scales
  • Public NASA data allows reproducible, open research

Discovery Pipeline

1. Data Acquisition

Query NEOWISE single-exposure time-series data from NASA IRSA.

2. Light Curve Construction

Group repeated observations into infrared brightness curves.

3. Feature Extraction

Compute statistical and periodicity-based variability features.

4. Machine Learning

Use Isolation Forests to identify anomalous objects.

5. Candidate Discovery

Flag objects absent or inconsistent with known catalogs.

Technical Details

Data Source: NASA IRSA NEOWISE Single-Exposure Database
Machine Learning: Isolation Forest anomaly detection
Features Analyzed: Magnitude statistics, amplitude, skewness, kurtosis, Lomb-Scargle periodogram
Quality Criteria: Minimum 15 observations per object, quality flag filtering
